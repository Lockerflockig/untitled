Eigene Sounds

1. Datei (wav, mp3 oder ogg) in diesen Ordner legen.
2. In sounds.json eintragen, z. B.:

   { "shoot": "pistole.wav", "explode": "boom.ogg" }

3. Neu bauen: docker compose up -d --build

Ein eingetragener Sound ersetzt den per Code erzeugten Platzhalter.
Mögliche Namen:

   shoot      Schuss (vorerst für alle Waffen)
   dash       Dash
   kick       Kick
   jump       Sprung
   slide      Slide
   hit        Schuss trifft
   kill       Gegner besiegt
   hurt       Figur getroffen
   explode    Explosion
   pickup     Banane aufgehoben
   roomClear  Raum geschafft
   die        Figur zerstört
   beep       Warnton, solange eine Sprengdrohne auf die Figur zuläuft
              (Dauerton, siehe unten)

Dauertöne

Der Warnton läuft als Schleife, solange seine Bedingung gilt, und endet sofort,
wenn sie nicht mehr gilt (auch bei Pause, Beute-Auswahl und Spielende). Er
piept schneller und höher, sobald die Lunte einer Sprengdrohne brennt. Die
Datei ist ein einzelner Piepton; das Spiel wiederholt sie im Takt.

Die Schleife lässt sich je Ton ausschalten. Dann ertönt der Ton nur einmal,
wenn die erste Sprengdrohne erscheint. Dafür statt des Dateinamens ein Objekt
eintragen:

   { "beep": { "datei": "piep.wav", "schleife": false } }

"schleife": false wirkt auch ohne "datei" – dann für den Platzhalter:

   { "beep": { "schleife": false } }
